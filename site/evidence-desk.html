How this monitoring works

GitHub Actions periodically checks a short allowlisted set of official webpages, comparing normalized page content with previous observations. First checks create baselines only. Detected differences remain unreviewed until independently examined; they should never be described as verified legal or policy changes.

Monitoring is intentionally lightweight and may miss changes or trigger on unrelated site updates. Sites can block automated retrieval. The implementation uses a minimal stdlib watcher, conceptually similar to urlwatch; no third-party page content is republished. For legal effect, read the primary notice or order itself.
