Method and permitted use

Original series are retrieved from the World Bank Indicators API for the selected countries. Only numeric published observations are included. Exports contain the same displayed records; dates are reference years, not fetch dates. Source-specific reuse and attribution terms still apply. For a larger offline table or SQL notebook, explore Datasette Lite (Apache-2.0).
